# assets

Coloca aquí `logo.png` (el logo real del negocio, idealmente cuadrado).

La app lo sirve automáticamente en `/logo.png` y lo usa como favicon, logo
del panel y de la pantalla de acceso. Si el archivo no existe, se cae a un
SVG terracota de respaldo. No requiere cambios de código: basta con que el
archivo esté presente al desplegar.
